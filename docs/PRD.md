## 1. 项目概述

### 1.1 背景
制造业数字化转型过程中，MES/ERP/OA 系统数据孤岛严重，缺乏统一的 AI 决策层。本项目旨在构建一个**工业智能体平台**，通过 MCP (Model Context Protocol) 协议连接 AI 与工厂数据，实现智能排产、预测维护、自动报工等场景。

### 1.2 目标
- **短期**: 打造可展示的工业 Agent 项目组合（简历级）
- **中期**: 实现单个工厂的数据打通与智能决策
- **长期**: 构建可复制的工业 AI 平台产品

### 1.3 目标用户
- 工厂生产管理人员
- 设备维护工程师  
- 质量控制人员
- 供应链协调员

## 2. 功能需求

### 2.1 MCP Server 层 (数据接入)

| 功能模块 | 优先级 | 描述 |
|---------|-------|------|
| 设备状态查询 | P0 | 实时查询 CNC、装配线等设备运行状态 |
| SOP 智能检索 | P0 | 基于关键词和语义搜索标准作业程序 |
| 产量统计接口 | P0 | 按日期/班次查询产出、缺陷、停机数据 |
| MES 数据接入 | P1 | 连接现有 MES 数据库 |
| ERP 库存查询 | P1 | 查询物料库存、采购订单状态 |
| OA 审批触发 | P1 | 自动发起报工、异常审批流程 |

### 2.2 Agent 层 (智能决策)

| 功能模块 | 优先级 | 描述 |
|---------|-------|------|
| 设备诊断 Agent | P0 | 基于设备数据生成 AI 诊断建议 |
| 排产优化 Agent | P1 | 根据订单和设备状态优化生产计划 |
| 异常预警 Agent | P1 | 检测异常模式，主动推送告警 |
| 知识问答 Agent | P2 | 基于工厂知识库回答操作问题 |

### 2.3 应用层 (用户界面)

| 功能模块 | 优先级 | 描述 |
|---------|-------|------|
| CLI 工具 | P0 | 命令行交互工具 |
| Web Dashboard | P1 | 生产看板、设备监控 |
| 移动端通知 | P2 | 异常告警推送 |

---

## 3. 非功能需求

### 3.1 性能要求
- API 响应时间 < 500ms (查询类)
- 支持并发 100+ 设备接入
- 数据延迟 < 5s (实时类)

### 3.2 可靠性
- 系统可用性 99.5%
- 数据持久化备份
- 故障自动恢复

### 3.3 安全
- 工控网与办公网隔离
- API 访问认证 (Token)
- 操作日志审计

### 3.4 可扩展性
- 模块化架构，支持新设备类型接入
- 插件化 Agent，支持自定义决策逻辑

## 4. 技术栈

| 层级 | 技术选型 |
|-----|---------|
| 协议层 | MCP (Model Context Protocol) |
| 后端 | Python 3.10+ / FastAPI |
| 数据库 | InfluxDB (时序) + PostgreSQL (业务) |
| 消息队列 | MQTT / Kafka |
| 前端 | React / Grafana |
| 部署 | Docker + Docker Compose |
| CI/CD | GitHub Actions |
